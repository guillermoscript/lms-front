## The QA harness

`scripts/qa-staff-theme-matrix.ts` (committed, new this session) is the authenticated sibling of
`scripts/qa-public-theme-matrix.ts` from #771. It logs in **once** and replays the storage state
into each theme × mode context, flips `tenant_settings.theme_preset` for the tenant through the 4
kits plus a no-row platform pass, restores the original row in a `finally`, and screenshots every
screen with an axe colour-contrast run per shot.

```bash
PORT=3005 npm run dev                       # tenant host is default.lvh.me:3005, never localhost
npx tsx scripts/qa-staff-theme-matrix.ts http://default.lvh.me:3005 ~/lms-764c-qa/after
node docs/handoff/764-surface3/scripts/axe-summary.mjs ~/lms-764c-qa/before ~/lms-764c-qa/after
npx tsx scripts/qa-contact-sheet.ts ~/lms-764c-qa/before ~/lms-764c-qa/after docs/qa/764c
npx tsx scripts/qa-theme-gif.ts onboarding-wizard ~/lms-764c-qa/before ~/lms-764c-qa/after docs/qa/764c/onboarding-themes.gif
```

Things about it worth knowing before you touch it:

- It runs on the **`default`** tenant (`…0001`) as `owner@e2etest.com`, not on code-academy — the
  default school is the one with transactions, payment requests, subscriptions and an exam
  submission, and an admin may enter `/dashboard/teacher` (`proxy.ts:497`).
- It **seeds fixtures idempotently** so a `master` run and a branch run see identical data: a
  pending `payment_requests` row, two `payouts`, two `invoices`, a `certificate_templates` row, and
  two `content_versions` for the richest lesson. Those rows are still in the local DB. `invoices.status`
  has no `open` — the values are draft/sent/paid/void/refunded.
- Tier A screens run all 10 combinations; tier B runs only `estructura|light` and `kodigo|dark`.
  ~15 minutes for the full pass.
- Four screens are behind a click and have a `prepare` step: the block palette (open the lesson
  editor's **Content** step first, then the `aria-label="Add block"` trigger), the landing-page
  template picker (**Get Started**), its second step (**Next**), and the version-history **Compare**
  view. If a selector drifts, the log says `PREPARE FAILED` and the shot is still taken — grep for it.
- `scalar()` gotcha already fixed but easy to reintroduce: `SELECT id::text … ORDER BY id` sorts the
  **output** column, i.e. as text, so `"1002"` beats `"10000"`. Qualify with the table alias.

## Traps that already cost time on this epic

- **The Edit tool trims a trailing space in `new_string`** — replacing `"bg-blue-500 "` glues the
  next class on and Tailwind drops both. It has shipped once already (#762).
- **A keep comment containing a literal utility class defeats the guard**, which is a text scan.
- **`--card` equals `--background` on the no-kit platform default**, so `bg-card` on a full-width
  band vanishes in light mode. Bands → `bg-muted`; bordered panels → `bg-card`.
- **`text-muted-foreground` on `bg-muted` is 4.39:1**, under AA — repo-wide since #770, follow-up 7 on #771.
- **Playwright `page.setContent()` + `file://` images renders broken-image icons** — write the HTML
  to a file and `goto('file://'+path)`. Open the output image before believing it.
- **Do not `git add -A` after a build** — `next build` rewrites `next-env.d.ts`.
- The dev server and local Supabase were left running. `PORT=3005`, tenant `default.lvh.me:3005`.
