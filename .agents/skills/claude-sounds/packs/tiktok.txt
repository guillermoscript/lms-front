# tiktok — meme sound pack. The default, and what claude-sounds shipped with.
#
# Format: <slot> <url>
# The installer downloads each to ~/.claude/hooks/sounds/<slot>.mp3.
#
# Sources are third-party uploads on myinstants.com, fetched to each user's own
# machine at install time and not redistributed by this repo. If a URL 404s the
# installer falls back to a spoken `say` voice for that slot.
#
# All URLs below were verified live (HTTP 200) and md5-distinct. myinstants
# serves a generic fallback file for dead slugs, so if you add a URL here,
# md5-check it against the others — a silent duplicate means the slug died.
